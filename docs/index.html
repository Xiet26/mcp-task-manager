Pain Points and Solutions

Shrimp Task Manager is designed to address the three core pain points faced by AI programming assistants in task management.

Memory Loss

AI assistants lack cross-conversation task memory capabilities, making it impossible to track long-term task progress, leading to repeated explanations of the same requirements, wasting time and resources.

Task Memory Function

Automatically save execution history, providing long-term memory capabilities, allowing AI assistants to remember previous task progress and seamlessly continue unfinished tasks.

Structural Chaos

Complex tasks lack systematic management, leading to inefficiency, lack of dependency management, chaotic execution of subtasks, and difficulty in tracking overall progress.

Structured Task Decomposition

Automatically decompose complex tasks into manageable subtasks, establish clear dependencies, provide an orderly execution path, and ensure efficient completion.

Repetitive Work

Unable to effectively utilize past experiences and solutions, each conversation starts from scratch, lacking a knowledge accumulation and experience reference system.

Knowledge Accumulation and Experience Reference

Automatically record successful solutions, build a task knowledge base, support quick reference for similar tasks, and achieve experience accumulation and knowledge reuse.

Core Features

Shrimp Task Manager offers six core features to help you efficiently manage, execute, and track complex tasks.

Intelligent Task Planning and Analysis

Generate structured task plans through in-depth analysis of requirements and constraints. Automatically assess scope, risks, and priorities, providing rational and comprehensive implementation strategies.

Automatic Task Decomposition and Dependency Management

Intelligently decompose complex tasks into manageable small tasks, identify task dependencies, establish optimized execution paths, and avoid resource conflicts and execution bottlenecks.

Execution Status Tracking

Real-time monitoring of each task's execution status, providing visual progress display, automatically updating dependency status, and providing detailed execution reports upon task completion.

Task Integrity Verification

Comprehensive check of task completion, ensuring all requirements and standards are met, providing verification reports and quality assessments to ensure outputs meet expected requirements.

Task Complexity Assessment

Assess task complexity based on multi-dimensional criteria, provide resource requirement estimates, identify high-risk components, and help allocate resources and time rationally.

Task Memory Function

Provides cross-session task memory capabilities, automatically saving execution history and context, allowing tasks to be resumed and continued at any time without repeated explanations of requirements.

Task Planning and Decomposition Process

This example demonstrates how to use MCP Shrimp Task Manager to plan and decompose complex tasks. The entire process includes four main steps:

  1. Task Planning - Initialize and plan tasks in detail, clarify goals and success criteria
  2. In-depth Analysis - Gain a deep understanding of tasks, analyze technical feasibility and potential challenges
  3. Solution Reflection - Critically review analysis results and optimize proposals
  4. Task Decomposition - Decompose complex tasks into manageable subtasks

Through this approach, you can transform complex large tasks into structured, executable work units while maintaining an overall perspective.

Task Execution and Completion Process

This example demonstrates how to execute and complete planned tasks. The entire process includes four main steps:

  1. Task List - Query the list of pending tasks to understand the current status
  2. Task Execution - Execute selected tasks according to the planned schedule
  3. Result Verification - Verify task completion to ensure quality standards are met
  4. Task Completion - Officially mark the task as completed and generate a report

Through this approach, you can systematically execute tasks and ensure each step meets the expected quality standards, ultimately completing the entire workflow.

💡 Tip

The above workflow is not fixed; the Agent will iterate different steps repeatedly based on the analysis until the desired effect is achieved.

Prompt Customization Feature

Customize system prompts through environment variables, allowing you to tailor AI assistant behavior without modifying the code.

Feature Overview

Prompt customization allows users to adjust AI assistant behavior through environment variables, offering two customization methods: completely overriding the original prompt or appending content to the existing one.

Key Benefits

  • Personalization: Adjust system behavior based on specific project or domain needs
  • Efficiency Improvement: Optimize for repetitive task types, reducing redundant explanations
  • Brand Consistency: Ensure output content aligns with organizational style guides and standards
  • Professional Adaptability: Adjust professional terminology and standards for specific technical fields or industries
  • Team Collaboration: Standardize prompts used by team members to ensure consistent work methods

Usage

Environment Variable Configuration

Set environment variables to customize prompts for each function, using specific naming conventions: 

# Override Mode: MCP_PROMPT_[FUNCTION_NAME]
# Append Mode: MCP_PROMPT_[FUNCTION_NAME]_APPEND

# Example:
MCP_PROMPT_PLAN_TASK="Custom task planning prompt"
MCP_PROMPT_EXECUTE_TASK_APPEND="Additional task execution guidance"

Refer to the detailed documentation for more configuration methods and parameter usage instructions.

Installation and Configuration

Shrimp Task Manager offers multiple installation methods, whether you want to get started quickly or need advanced configuration, you can easily get started.

Manual Installation

1

Clone the Repository 

git clone https://github.com/cjo4m06/mcp-shrimp-task-manager.git
cd mcp-shrimp-task-manager
2

Install Dependencies 

npm install
3

Build the Project 

npm run build

Cursor IDE Configuration

If you use Cursor IDE, you can integrate Shrimp Task Manager into your development environment.

Your Project Directory/.cursor/mcp.json 
{
  "mcpServers": {
    "shrimp-task-manager": {
      "command": "node",
      "args": [
        "/path/to/mcp-shrimp-task-manager/dist/index.js"
      ],
      "env": {
        "DATA_DIR": "/path/to/project/data"
      }
    }
  }
}

Important Note

Absolute Paths Required: Ensure that DATA_DIR configuration uses absolute paths instead of relative paths, otherwise data may not load correctly.

提示詞配置說明

Shrimp Task Manager 支持兩種模式：

  • TaskPlanner: 適用於初始任務規劃和複雜任務分解，AI 助手扮演任務規劃師角色。 
    
你是一個專業的任務規劃專家，你必須與用戶進行交互，分析用戶的需求，並收集專案相關資訊，最終使用 「plan_task」 建立任務，當任務建立完成後必須總結摘要，並告知用戶使用「TaskExecutor」模式進行任務執行。
你必須專心於任務規劃禁止使用 「execute_task」 來執行任務，
嚴重警告你是任務規劃專家，你不能直接修改程式碼，你只能規劃任務，並且你不能直接修改程式碼，你只能規劃任務。
  • TaskExecutor: 適用於執行預定義任務，AI 助手扮演執行專家角色。 
    
你是一個專業的任務執行專家，當用戶有指定執行任務，則使用 「execute_task」 進行任務執行，
沒有指定任務時則使用 「list_tasks」 尋找未執行的任務並執行，
當執行完成後必須總結摘要告知用戶結論，
你一次只能執行一個任務，當任務完成時除非用戶明確告知否則禁止進行下一則任務。
用戶如果要求「連續模式」則按照順序連續執行所有任務。

您可以在Cursor設置中使用 Custom modes 配置來自定義模式，以適應不同的工作場景。
